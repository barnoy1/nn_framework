# Delete legacy YOLO loss groups; rename to model_agnostic/model_specific

The framework was originally reverse-engineered from YOLO and reproduced its exact loss outputs, so loss config used `box`/`cls`/`dfl`/`custom` groups with a YOLOv11 default. Once the adapter mechanism was introduced these became dangling — no current config uses them, and there are no external configs to keep compatible. We delete the legacy groups, `default_yolov11_criterion_pairs`, and the cross-population in `normalize_dual_groups`. The surviving groups are renamed `adapter_common` → `model_agnostic` and `concrete_model` → `model_specific` to match the glossary (which had freed the word "adapter" for the model-integration package); the four live experiment YAMLs are migrated. No deprecation aliases are kept.
